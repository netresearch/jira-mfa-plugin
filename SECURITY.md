# Security policy

This plugin is an authentication control, so please report suspected vulnerabilities privately.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Please do not open a public issue for a security problem.

Include the plugin version, the Jira version, and the steps or request sequence that reproduce the problem. We will acknowledge the report, keep you informed about the fix and credit you in the advisory unless you prefer otherwise.

## Supported versions

Only the latest release receives security fixes.
